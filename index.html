Optimizacion del sistema

Consejos para mejorar el rendimiento en PCs limitadas.

Desactivar servicios innecesarios

Lista servicios activos y deshabilita los que no uses.

systemctl list-unit-files --type=service --state=enabled
sudo systemctl disable nombre-servicio

Reducir uso de swap

Baja el valor swappiness para priorizar RAM.

cat /proc/sys/vm/swappiness
echo 10 | sudo tee /proc/sys/vm/swappiness
# Permanente en /etc/sysctl.conf:
vm.swappiness=10

Limpiar paquetes y cache

Elimina paquetes huerfanos y cache de APT.

sudo apt autoremove -y
sudo apt clean
sudo apt autoclean

Usar un gestor ligero

En PCs con poca RAM, usa gestores de ventanas minimalistas.

Opciones: i3, openbox, fluxbox, icewm. En antiX ya viene uno ligero.

Preload

Instala preload para acelerar el arranque de aplicaciones frecuentes.

sudo apt install preload

Guia de instalacion antiX

Paso a paso para instalar antiX Linux en tu PC.

1. Descargar antiX

Obtiene la imagen ISO desde antixlinux.com. Elige la version segun tu arquitectura (64-bit o 32-bit) y tu entorno de escritorio preferido.

2. Verificar la ISO

Comprueba la integridad del archivo descargado con el checksum SHA256.

sha256sum antix-xx.iso
# Compara con el valor publicado en la web oficial

3. Crear USB booteable

Usa dd o Rufus/etcher para grabar la ISO en un pendrive.

sudo dd if=antix-xx.iso of=/dev/sdX bs=4M status=progress && sync

4. Arrancar desde USB

Reinicia el PC y entra al BIOS/UEFI (tecla Del, F2, F12 o Esc segun el fabricante). Configura el USB como primer dispositivo de arranque.

5. Seleccionar modo de inicio

En el menu de antiX, elige el modo que mejor se adapte a tu hardware: "antiX con kernel", "antiX sin firmware" o modo seguro si hay problemas de compatibilidad.

6. Probar en modo Live

antiX permite probar el sistema sin instalar. Verifica que el wifi, audio y video funcionen correctamente.

7. Iniciar instalacion

Haz clic en el icono "Install antiX" en el escritorio o ejecuta sudo antixinstaller desde la terminal.

8. Seleccionar idioma y teclado

Elige espanol como idioma y la distribucion de teclado correspondiente (latinoamericano, espanol, etc.).

9. Particionar disco

Para principiantes: selecciona "Usar todo el disco". Para avanzados: crea particiones manualmente (/, /home, swap).

# Ejemplo con fdisk:
sudo fdisk /dev/sda

10. Configurar usuario

Define nombre de usuario, contraseña y contraseña de root. No dejes la contraseña de root vacia por seguridad.

11. Instalar gestor de arranque

Selecciona GRUB como gestor de arranque e instalalo en el MBR o particion EFI segun tu sistema.

12. Finalizar instalacion

Espera a que el instalador copie todos los archivos. Al terminar, retira el USB y reinicia.

13. Primer arranque y post-instalacion

Actualiza el sistema e instala herramientas adicionales:

sudo apt update && sudo apt upgrade -y
sudo apt install firmware-linux-nonfree
