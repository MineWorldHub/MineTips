antiX Linux

Distribución Linux ultra-ligera ideal para PCs con pocos recursos. Funciona en computadoras con tan solo 256MB de RAM. Perfecta para revivir PCs antiguas y ejecutar Minecraft con el mínimo overhead del sistema operativo.

OptiFine vs Sodium 🔗

¿Qué mod de rendimiento elegir para tu PC?

OptiFine

OptiFine

  • Funciona con Forge
  • Soporta shaders (SEUS, BSL, etc.)
  • Configuración visual detallada
  • Más pesado que Sodium
  • Actualizaciones lentas

Ideal si quieres shaders y usas Forge.

Sodium

Sodium

  • Funciona con Fabric
  • Mejora FPS hasta 5x vs vanilla
  • Más ligero y rápido
  • No soporta shaders directamente
  • Compatible con Iris (shaders)

Mejor opción para PCs de bajos recursos.

Configurar servidor Minecraft 🔗

Guía para montar un servidor ligero en una PC vieja.

1. Requisitos mínimos

2GB RAM, CPU dual-core, conexión estable. Para PCs limitadas: servidor paper en vez de vanilla.

2. Descargar server.jar

Usa PaperMC para mejor rendimiento en PCs limitadas: papermc.io

3. Script de inicio

java -Xmx2G -Xms1G -jar server.jar nogui

4. Configurar server.properties

Ajusta: view-distance=4, simulation-distance=4, max-players=10 para ahorro de RAM.

5. Abrir puerto

sudo ufw allow 25565/tcp

Memoria GPU y Minecraft 🔗

Cómo la VRAM afecta el rendimiento.

GPU integrada (Intel/AMD)

Comparte RAM con el sistema. Asigna más RAM en BIOS si es posible. Minecraft funciona con 512MB VRAM.

GPU dedicada (Nvidia/AMD)

Tiene VRAM propia. 1GB+ es suficiente para Minecraft. Drivers actualizados mejoran mucho.

Guía Trinity Launcher 🔗

Launcher comunitario para Minecraft Bedrock en Linux (Flatpak / AppImage / macOS).

1. Instalar Flatpak (si no lo tienes)

sudo apt install flatpak
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo

2. Agregar repositorio Trinity

flatpak remote-add trinity https://github.com/Trinity-LA/Trinity-Launcher/releases/download/flatpak/com.trench.trinity.launcher.flatpakrepo

3. Instalar dependencias (KDE runtime + Qt WebEngine)

flatpak install flathub org.kde.Platform//6.10 io.qt.qtwebengine.BaseApp//6.10

4. Instalar Trinity Launcher

flatpak install com.trench.trinity.launcher

5. Ejecutar Trinity Launcher

flatpak run com.trench.trinity.launcher

También puedes buscar "Trinity Launcher" en el menú de aplicaciones.

Alternativa: AppImage (portable)

Descarga el archivo .AppImage desde el repositorio de Trinity, dale permisos de ejecución y ejecútalo directamente. Sin instalación necesaria.

chmod +x TrinityLauncher.AppImage
./TrinityLauncher.AppImage

Alternativa: macOS (DMG)

Descarga el archivo .dmg, mueve Trinity.app a /Applications y ejecútalo desde la terminal:

cd /Applications/Trinity.app/Contents/MacOS/
./trinity-bin

Si macOS bloquea la app, ve a Configuración del Sistema → Privacidad y Seguridad → Abrir de todos modos.

Linux 🔗

Comandos, optimización y diagnóstico para tu sistema Linux.

Optimización del sistema

Consejos para mejorar el rendimiento en PCs limitadas.

Desactivar servicios innecesarios

Lista servicios activos y deshabilita los que no uses.

systemctl list-unit-files --type=service --state=enabled
sudo systemctl disable nombre-servicio

Reducir uso de swap

Baja el valor swappiness para priorizar RAM.

cat /proc/sys/vm/swappiness
echo 10 | sudo tee /proc/sys/vm/swappiness
# Permanente en /etc/sysctl.conf:
vm.swappiness=10

Limpiar paquetes y cache

sudo apt autoremove -y
sudo apt clean

zRAM para compresión en RAM

zRAM comprime datos en RAM en vez de usar swap en disco.

sudo modprobe zram
echo lz4 > /sys/block/zram0/comp_algorithm
echo 2G > /sys/block/zram0/disksize
mkswap /dev/zram0
swapon /dev/zram0

SWAP permanente

sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
# En /etc/fstab:
/swapfile none swap sw 0 0

Drivers Nvidia en Linux

# Verificar GPU:
lspci | grep -i nvidia
# Instalar drivers:
sudo apt install nvidia-driver
# O usar el .run oficial:
chmod +x NVIDIA-Linux-x86_64.run
sudo ./NVIDIA-Linux-x86_64.run

Dual boot Linux + Windows 🔗

Cómo tener ambos sistemas en tu PC.

1. Hacer espacio

Reduce la partición de Windows desde Administrador de discos. Mínimo 20GB para Linux.

2. Crear USB de instalación

Usa Rufus o dd para grabar la ISO de Linux en un USB.

3. Instalar Linux

Arranca desde USB. En particionamiento, selecciona el espacio libre. Instala GRUB.

4. Configurar GRUB

GRUB detectará Windows automáticamente. Si no: sudo os-prober && sudo update-grub

Corregir audio en Linux 🔗

Problemas comunes de sonido y sus soluciones.

Sin sonido

Guía de instalación antiX 🔗

Paso a paso para instalar antiX Linux en tu PC.

1. Descargar antiX

Obtén la imagen ISO desde antixlinux.com. Elige la versión según tu arquitectura (64-bit o 32-bit) y tu entorno de escritorio preferido.

2. Verificar la ISO

Comprueba la integridad del archivo descargado con el checksum SHA256.

sha256sum antix-xx.iso

3. Crear USB booteable

Usa dd o Rufus/etcher para grabar la ISO en un pendrive.

sudo dd if=antix-xx.iso of=/dev/sdX bs=4M status=progress && sync

4. Arrancar desde USB

Reinicia el PC y entra al BIOS/UEFI (tecla Del, F2, F12 o Esc según el fabricante). Configura el USB como primer dispositivo de arranque.

5. Seleccionar modo de inicio

En el menú de antiX, elige el modo que mejor se adapte a tu hardware: "antiX con kernel", "antiX sin firmware" o modo seguro si hay problemas de compatibilidad.

6. Probar en modo Live

antiX permite probar el sistema sin instalar. Verifica que el wifi, audio y video funcionen correctamente.

7. Iniciar instalación

Haz clic en el icono "Install antiX" en el escritorio o ejecuta sudo antixinstaller desde la terminal.

8. Seleccionar idioma y teclado

Elige español como idioma y la distribución de teclado correspondiente (latinoamericano, español, etc.).

9. Particionar disco

Para principiantes: selecciona "Usar todo el disco". Para avanzados: crea particiones manualmente (/, /home, swap).

10. Configurar usuario

Define nombre de usuario, contraseña y contraseña de root. No dejes la contraseña de root vacía por seguridad.

11. Instalar gestor de arranque

Selecciona GRUB como gestor de arranque e instálalo en el MBR o partición EFI según tu sistema.

12. Finalizar instalación

Espera a que el instalador copie todos los archivos. Al terminar, retira el USB y reinicia.

13. Primer arranque y post-instalación

Actualiza el sistema e instala herramientas adicionales:

sudo apt update && sudo apt upgrade -y
sudo apt install firmware-linux-nonfree
