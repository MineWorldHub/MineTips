Minecraft no longer runs well on your old PC: what to do 🔗

The new July 2026 minimum requirements, explained without jargon — and what to do if your PC does not meet them.

What changed exactly

On July 21, 2026, Mojang Studios updated Minecraft: Java Edition system requirements for the first time in 17 years. It is the biggest requirements change since the game launched in 2011.

The new target minimum is 1080p at 30 FPS with the “Fast” preset. These are targets for the current experience; Mojang notes that the game may still start on lower-end hardware, but performance and visual quality are not guaranteed.

  • 64-bit operating system (32-bit Windows/PCs are on the way out)
  • 4-core processor
  • GPU compatible with Vulkan 1.3, with at least 2GB of VRAM
  • 8GB of RAM with a dedicated GPU, or 12GB with integrated graphics

The recommended target is 1080p at 60 FPS with the “Fabulous” preset: 16GB RAM, a modern mid-range processor and a GPU with 6GB VRAM.

Why they changed it

The reason is the graphics-engine transition: Minecraft is moving from OpenGL to Vulkan. Vulkan is intended to improve modern CPU/GPU utilization and enables future visual features such as Vibrant Visuals and ray tracing.

Is your PC too old for Minecraft?

These requirements are not necessarily an immediate hard block. They are performance targets. If your PC does not meet them, Minecraft may still start and run, but with lower FPS, occasional graphics issues or slower loading.

The main hard exception is 64 bits: a 32-bit CPU or operating system may eventually stop being supported.

What to do on a low-end PC

Option 1

Use an older version

1.8.9 o 1.12.2 siguen funcionando perfecto en hardware limited y no dependen de estos requirements nuevos.

Open recommender
Option 2

Optimization mods

Sodium (Fabric) or OptiFine (Forge) can improve smoothness, but results depend on the GPU, CPU, version and settings.

View mods
Option 3

Update drivers

Muchas GPUs integradas ya soportan Vulkan 1.3, solo necesitan drivers actualizados.

Option 4

Try a lightweight Linux distro

antiX can leave more resources available for games on older hardware than a heavier desktop environment.

Open the antiX guide

How to check whether your PC meets the requirements

  • 64 bits: in Windows, Settings → System → About → “System type”
  • RAM: mismo lugar, "RAM instalada"
  • Vulkan de your GPU: en Linux, ejecuta vulkaninfo (instala with sudo apt install vulkan-tools)
In summary: requirements have increased, but an older PC is not automatically useless. The right Minecraft version, optimization mods and a lightweight Linux setup can extend its useful life.

Set up a Minecraft server 🔗

Guide to setting up a lightweight server on an old PC.

1. Minimum requirements

2GB RAM, a dual-core CPU and a stable connection. On limited PCs, Paper is usually preferable to vanilla.

2. Download server.jar

Use PaperMC for better performance on limited hardware: papermc.io

3. Startup script

java -Xmx2G -Xms1G -jar server.jar nogui

4. Configure server.properties

Set view-distance=4, simulation-distance=4 and max-players=10 to reduce resource usage.

5. Open port

sudo ufw allow 25565/tcp

GPU memory and Minecraft 🔗

How VRAM affects performance.

Integrated GPU (Intel/AMD)

Integrated graphics share system RAM. BIOS memory settings vary by system; do not assume increasing shared memory improves FPS. Minecraft requirements depend on the version and renderer.

Dedicated GPU (Nvidia/AMD)

Has dedicated VRAM. The amount required depends on the Minecraft version, resolution, renderer and graphics settings.

Trinity Launcher guide 🔗

Community launcher for Minecraft Bedrock on Linux (Flatpak / AppImage / macOS).

1. Install Flatpak (si no lo tienes)

sudo apt install flatpak
flatpak remote-add --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo

2. Add repositorio Trinity

flatpak remote-add trinity https://github.com/Trinity-LA/Trinity-Launcher/releases/download/flatpak/com.trench.trinity.launcher.flatpakrepo

3. Install dependencias (KDE runtime + Qt WebEngine)

flatpak install flathub org.kde.Platform//6.10 io.qt.qtwebengine.BaseApp//6.10

4. Install Trinity Launcher

flatpak install com.trench.trinity.launcher

5. Ejecutar Trinity Launcher

flatpak run com.trench.trinity.launcher

You can also search for “Trinity Launcher” in your applications menu.

Alternativa: AppImage (portable)

Download the .AppImage file from the Trinity repository, make it executable, and run it directly. No installation is required.

chmod +x TrinityLauncher.AppImage
./TrinityLauncher.AppImage

Alternativa: macOS (DMG)

Download the .dmg file, move Trinity.app to /Applications, and launch it from the terminal:

cd /Applications/Trinity.app/Contents/MacOS/
./trinity-bin

If macOS blocks the app, go to System Settings → Privacy & Security → Open Anyway.

Linux 🔗

Commands, optimization and diagnostics for your Linux system.

System optimization

Consejos for improve el performance en PCs limitadas.

Gestionar servicios

antiX does not use systemd by default. Use the service manager provided by your system; the commands systemctl solo aplican a distros with systemd.

service --status-all
# Detén un servicio solo si sabes que no lo necesitas:
sudo service name-servicio stop

Networkucir uso de swap

Lower swappiness to reduce the tendency to use swap.

cat /proc/sys/vm/swappiness
echo 10 | sudo tee /proc/sys/vm/swappiness
# Permanente en /etc/sysctl.conf:
vm.swappiness=10

Limpiar paquetes y cache

sudo apt autoremove -y
sudo apt clean

zRAM for in-RAM compression

zRAM comprime datos en RAM en vez de use swap en disco.

sudo modprobe zram
echo lz4 | sudo tee /sys/block/zram0/comp_algorithm >/dev/null
echo 2G | sudo tee /sys/block/zram0/disksize >/dev/null
sudo mkswap /dev/zram0
sudo swapon /dev/zram0

SWAP permanente

sudo fallocate -l 2G /swapfile
sudo chmod 600 /swapfile
sudo mkswap /swapfile
sudo swapon /swapfile
# En /etc/fstab:
/swapfile none swap sw 0 0

Drivers Nvidia en Linux

# Verificar GPU:
lspci | grep -i nvidia
# Install drivers:
sudo apt install nvidia-driver
# O use el .run official:
chmod +x NVIDIA-Linux-x86_64.run
sudo ./NVIDIA-Linux-x86_64.run

Linux + Windows dual boot 🔗

How to keep both systems on your PC.

1. Hacer espacio

Shrink the Windows partition from Disk Management. Leave at least 20GB for Linux.

2. Crear USB de Installation

Use Rufus, balenaEtcher or dd to write the Linux ISO to a USB drive.

3. Install Linux

Arranca from USB. En particionamiento, select el espacio libre. Instala GRUB.

4. Configurar GRUB

GRUB should detect Windows automatically. If it does not: sudo os-prober && sudo update-grub

guide de Installation antiX 🔗

Paso a paso for Install antiX Linux en your PC.

1. Download antiX

Get the ISO image from antixlinux.com. Elige la version depending on your arquitectura (64-bit o 32-bit) y your entorno de escritorio preferido.

2. Verificar la ISO

Verify the integrity of the downloaded file with its SHA256 checksum.

sha256sum antix-xx.iso

3. Crear USB booteable

use dd o Rufus/etcher for grabar la ISO en un pendrive.

sudo dd if=antix-xx.iso of=/dev/sdX bs=4M status=progress && sync

4. Arrancar from USB

Reinicia el PC y entra al BIOS/UEFI (tecla Del, F2, F12 o Esc depending on el fabricante). Configura el USB como primer dispositivo de arranque.

5. select modo de home

In the antiX menu, choose the mode that best fits your hardware: “antiX with kernel”, “antiX without firmware”, or safe mode if you have compatibility problems.

6. Probar en modo Live

antiX lets you test the system without installing it. Verify that Wi-Fi, audio and video work correctly.

7. Iniciar Installation

Click the “Install antiX” icon on the desktop or open the installer from the antiX applications menu (Install antiX).

8. select idioma y teclado

Choose your preferred language and the appropriate keyboard layout.

9. Particionar disco

for principiantes: select "use todo el disco". for avanzados: crea particiones manualmente (/, /home, swap).

10. Configurar user

Set the username, user password and root password. Do not leave the root password blank.

11. Install gestor de arranque

select GRUB as the bootloader and install it to the MBR or EFI partition, depending on your system.

12. Finalizar Installation

Wait for the installer to copy all files. When it finishes, remove the USB drive and reboot.

13. Primer arranque y post-Installation

Update el system e instala tools adicionales:

sudo apt update && sudo apt upgrade -y
sudo apt install firmware-linux-nonfree
